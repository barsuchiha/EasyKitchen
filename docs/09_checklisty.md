# Шаблоны и чеклисты

## 1. Чеклист после магазина

```text
[ ] убрать все скоропортящееся в холодильник/морозилку
[ ] сырое мясо поставить вниз
[ ] разделить мясо/рыбу на порции
[ ] подписать пакеты для морозилки
[ ] перебрать ягоды
[ ] разобрать зелень
[ ] вынести продукты "на ближайшие 2 дня" вперед
```

## 2. Чеклист раз в неделю

```text
[ ] проверить зону "съесть первым"
[ ] проверить остатки
[ ] проверить молочку и открытые банки
[ ] посмотреть морозилку
[ ] составить 2-3 блюда из того, что уже есть
[ ] только потом писать список покупок
```

## 3. Маркировка для морозилки

```text
Продукт:
Дата:
Вес/порция:
До какой даты использовать:
```

## 4. Мини-инвентарь морозилки

```text
Дата     | Продукт           | Кол-во | Примечание
---------|-------------------|--------|-----------
05.04    | Курица бедро      | 3      | по 450 г
05.04    | Ягоды             | 2      | для каши
05.04    | Овощная смесь     | 4      | суп/рагу
```

## 5. Список "съесть первым"

```text
На этой неделе съесть:
- зелень
- ягоды
- открытый сыр
- остатки супа
- половину кабачка
```

## 6. Моя простая кухонная формула

```text
Купила -> Разложила -> Подписала -> Увидела -> Съела или заморозила
```

Если один шаг выпадает, продукты начинают портиться.
